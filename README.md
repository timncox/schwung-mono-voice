# Mono Voice

Mono Voice is the single-track version of the clean-room,
Monomachine-inspired [Mono](https://github.com/timncox/schwung-mono)
instrument for Ableton Move. It runs as a normal Schwung sound generator, so
Move keeps control of the track, pads, clips, sequencing, and surrounding
effects.

This repository is the dedicated installation and release surface for the
`mono-voice` module. Development and canonical source history remain in
[timncox/schwung-mono](https://github.com/timncox/schwung-mono), where Mono
Voice shares its synthesis engine with the six-track standalone instrument.

## Install with Schwung Manager

Open **Modules → Custom Install → From GitHub URL** and enter:

```text
https://github.com/timncox/schwung-mono-voice
```

Or download `mono-voice-module.tar.gz` from the latest release and use
**Custom Install → Upload Tarball**.

## Manual

The interactive manual and complete parameter reference are available at
[timncox.github.io/schwung-mono](https://timncox.github.io/schwung-mono/).

## Releases

Release tags mirror the matching `mono-voice-module.tar.gz` built from the
canonical Mono source tag. The workflow verifies the archive ID and embedded
module version before publishing it here.
